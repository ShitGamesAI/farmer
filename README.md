# ТУН ТУН ФЕРМА

Ферма ИИ-зверят на Electron. Строишь клетки, заселяешь ИИ Клубнику и ИИ Банана, они несут яйца с рандомными мутантами. Со всех сторон летят дроны, а вокруг четыре соседские фермы: с ними можно дружить через послов или воевать набегами Тун Тун Сахуров и Бомбардиро Крокодило. Цель — захватить всех соседей.

```bash
npm install
npm start
```

## Управление

| Клавиша | Действие |
|---|---|
| ЛКМ по дрону / вражескому сахуру / бомбардиро | ударить (оружие качается кнопкой 4) |
| ЛКМ по своей постройке, зверьку, пустому участку | меню: заселить, продать, починить, расчистить |
| ЛКМ по чужой ферме или карточке справа | дипломатия |
| 1 / 2 / 3 | поставить клетку / сахурню / ангар |
| 4 / 5 | новое оружие / качалка сахуров |
| колесо | зум |
| ПКМ-перетаскивание / WASD / стрелки | двигать карту |
| клик по миникарте | прыгнуть туда |
| H | к своей ферме |
| N | следующая волна сразу (за бонус) |
| ПКМ / Esc | отмена |
| Пробел / P | пауза |
| M | звук |
| F11 | фуллскрин |

## Ферма

- **Клетка** на 3 зверят. Двое в клетке несут яйцо каждые 20 с. Из яйца: копия родителя, рецепт (клубника + банан → вишня), мутация на редкость выше, очень редко сахур или дрон.
- **Редкости:** обычный → необычный → редкий → ЭПИК → ЛЕГЕНДА. Чем реже, тем больше монет.
- **Сахурня** рожает Тун Тун Сахуров. Они бьют дронов, защищают от набегов и сами ходят в набеги. Ушедшие в набег не освобождают место в сахурне.
- **Ангар** выпускает Бомбардиро Крокодило (до 2). Крокодилов из клеток тоже можно призвать в ангар.
- **Дроны:** синие воруют зверят (собьёшь похитителя — зверёк вернётся), красные таранят постройки, серые жгут лазером, каждая 5-я волна — МЕГАДРОН-3000. Дроны нападают и на соседей.

## Соседи

| Ферма | Маскот | Характер |
|---|---|---|
| Ранчо Бобрито | 🦫 | агрессивные, требуют дань |
| Капучино Корп | ☕ | средние |
| Шимпанзини Плантейшн | 🐒 | мирные |
| Тралалело Холдинг | 🦈 | средние |

- **Посол.** Отправляешь своего зверька. У соседей он заводит яйцо с их маскотом. Родился кто-то из родителей — союз. Мутация — союз и подарок. Кто-то чужой — «ЭТО НЕ ОТ НАС!» и война. Если отправить их любимчика, у яйца будет второй шанс.
- **Союзники** присылают монеты и зверят и вступают в твои войны. Иногда предают.
- **Война.** «Набег» отправляет 60% твоих сахуров на их ферму, «Бомбить» — одного Бомбардиро. Защитники на своей земле бьют сильнее, поэтому для штурма нужна толпа, прокачка или бомбардировщики. Мир покупается за монеты, иногда враг сам предлагает мир и платит.
- **Захват.** Сломал главный амбар соседа — его земля, постройки, зверята и сахуры становятся твоими. Захватил всех четверых — победа (можно играть дальше).
- **Дань.** Агрессивные соседи требуют монеты: не заплатишь за 30 секунд — война. Требует только один сосед за раз и никогда, пока ты уже с кем-то воюешь.
- Сами соседи начинают войну с тобой, только когда ты ни с кем не воюешь. В чужие войны тебя не втягивают, а твои союзники вступают в твои.
- Соседи воюют и между собой (их набеги обходят твою ферму стороной). Могут захватить друг друга.
- На карточке соседа видно его монеты, доход, сахуров и их уровень. Соседи зарабатывают меньше тебя, и у их казны есть потолок.
